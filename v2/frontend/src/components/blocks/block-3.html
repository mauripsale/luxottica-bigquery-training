Ecco il momento decisivo: incrociare la spesa marketing per canale con le vendite e-commerce reali. Devi calcolare il ROAS (Return on Ad Spend) evitando la trappola del Fan-Out SQL (duplicazione dei ricavi). Scoprirai chi genera redditività stellare e chi brucia cassa aziendale su traffico freddo!

🎯 La Sfida dell'Attribution (Evitare il SQL Fan-Out):

I dati di spesa (lux_ad_spend) e di vendita (lux_online_orders) hanno granularità diverse. Un JOIN diretto causerebbe duplicazioni moltiplicando i ricavi! Usa le CTE (Common Table Expressions) per pre-aggregare i totali per brand, poi unisci con JOIN e calcola il ROAS (Ricavi / Spesa).

💡
Query Soluzione Docente (Opzionale / Solo se bloccato):

Non serve per rispondere alla sfida. Sblocca solo se hai bisogno del codice SQL suggerito.

WITH spend_summary AS (
  SELECT 
    brand, 
    platform, 
    ROUND(SUM(spend_eur), 2) AS total_spend
  FROM `qwiklabs-asl-02-9bb3224716de.luxottica_marketing_analytics.lux_ad_spend`
  GROUP BY brand, platform
),
revenue_summary AS (
  SELECT 
    brand, 
    ROUND(SUM(revenue_eur), 2) AS total_revenue
  FROM `qwiklabs-asl-02-9bb3224716de.luxottica_marketing_analytics.lux_online_orders`
  GROUP BY brand
)
SELECT 
  s.platform, 
  s.brand, 
  s.total_spend, 
  r.total_revenue, 
  ROUND(SAFE_DIVIDE(r.total_revenue, s.total_spend), 2) AS roas_multiplier
FROM spend_summary s
JOIN revenue_summary r ON s.brand = r.brand
ORDER BY roas_multiplier DESC;
